# 拖炮小队

单指驾驶装甲车队，沿敌群外侧转弯，让不同炮节的火力在怪群中交叉。两门炮从不同方向覆盖同一只敌人时，双环会亮起，点击齐射可打出夹击爆破。

[手机直接开玩](https://softxuep-dotcom.github.io/PaoChe/)

- **快速试打**约 90 秒，先体验一次齐射，再沿青色指引练习主动摆出第二次夹击。
- **完整战斗**约 4–6 分钟，分段补给可以接炮、合并强化或维修。
- 手机拖动移动，点击齐射。电脑可用 WASD／方向键与空格，Esc 暂停。
- 尾炮脱钩后可绕回拾取零件，抢救一次。守卫冲锋结束后会露出两侧弱点。
- 穿岩前炮擅打护甲，霜火尾炮减慢追兵。整备时可以指定强化哪节炮。
- 作战档案保存两种模式的最快通关、夹击、单发击毁纪录和徽章，记录保存在当前浏览器。
- 地图、车队、特效和音效由程序生成。在线版复用《元素破潮》的敌人图集，离线单文件带有程序绘制的备用敌人。

## 本地运行

需要 Node.js 22.12+ 或 24。

```sh
npm ci
npm run dev
```

打开 `http://localhost:5177`。需要 Canvas 兼容路径时在网址末尾加 `?canvas=1`。

```sh
npm test
npm run build
```

构建输出包含网站入口 `dist/index.html` 和可用浏览器直接离线打开的 `dist/拖炮小队.html`。发布配置以 `main` 为源，构建通过后更新 GitHub Pages。

首版玩法和范围见 [PLAN.md](PLAN.md)。模型测试覆盖实际夹击、补给、暂停、掉车抢救、首领破防、胜负和重开。
